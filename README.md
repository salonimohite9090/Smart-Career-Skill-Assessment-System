# Smart Career & Skill Assessment System

## Project Overview

The Smart Career & Skill Assessment System is a Python-based application designed to assess students' skills and recommend suitable career paths based on their self-assessed skill ratings.

The system collects student information, evaluates six skills, calculates career scores using predefined rules, identifies strengths and areas for improvement, and provides career-specific learning roadmaps.

## Project Objectives

- Collect and validate student information.
- Evaluate individual skills through a rating-based assessment.
- Recommend suitable career paths based on skill scores.
- Identify strong skills and areas requiring improvement.
- Provide structured learning roadmaps for recommended careers.

## Skills Assessed

The application evaluates six skills using a rating scale of 1 to 10:

- Python
- SQL
- Communication
- Problem Solving
- Excel
- Web Development

## Career Recommendations

The system evaluates five career paths:

1. Data Analyst
2. Python Developer
3. Web Developer
4. Business Analyst
5. Software Developer

Career recommendations are generated using predefined skill combinations and rule-based scoring.

## How the Application Works

1. Collects the student's name, age and education.
2. Asks the student to rate six skills from 1 to 10.
3. Calculates scores for five career paths.
4. Identifies the highest-scoring career recommendation.
5. Displays the student's strong skills and skills to improve.
6. Provides a learning roadmap when one career receives the highest score.
